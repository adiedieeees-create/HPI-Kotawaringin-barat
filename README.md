# HPI Kotawaringin Barat

Website informasi dan promosi Himpunan Pramuwisata Indonesia (HPI) DPC Kotawaringin Barat, Kalimantan Tengah.

## Fitur
- Profil organisasi dan informasi kepramuwisataan
- Informasi destinasi wisata lokal
- Layanan pemandu wisata
- Galeri dan kontak
- Desain responsif untuk desktop dan perangkat mobile

## Menjalankan secara lokal
Buka `index.html` melalui browser atau jalankan server lokal:

```bash
python -m http.server 8000
```

Kemudian buka http://localhost:8000.

## Catatan
Konten kepengurusan, kontak, daftar guide, dan detail layanan perlu diverifikasi serta diperbarui oleh pengurus HPI sebelum dipublikasikan sebagai informasi resmi.
